# 11. The Description-Discernment loop (exercise lesson, no video)

Estimated time: 30 to 60 min

## Learning objectives
- Apply Description and Discernment to a real project
- Run productive Description-Discernment feedback loops
- Produce results through human-AI collaboration that **exceed what either could do alone**

## The exercise: execute the project you planned
(The project plan from lesson 7, "Project planning and Delegation". The course page calls it "Lesson 5" using its own numbering.)

### Step 1: Review your project plan
- Pull up the plan and re-check your delegation decisions (human expertise vs. AI capability vs. collaboration).
- Refine it with what you have learned since.

### Step 2: Prepare your Description approach
Before executing, explain the project to Claude and agree on:
- **Product**: what outputs per task? format, style, length, level of detail?
- **Process**: how should Claude approach each task? specific methods, frameworks, steps?
- **Performance**: what collaborative behaviour? concise or detailed, challenging or supportive, focused on ideas or analysis?

Discuss these with Claude to set clear expectations.

### Step 3: Run the loop for each task
1. **Describe** clearly
   - what you want (Product)
   - how Claude should approach or think about it (Process)
   - how it should engage with you (Performance)
2. **Discern** what you get
   - evaluate the output (Product)
   - assess how Claude approached it (Process)
   - consider whether its behaviour is most helpful (Performance)
3. **Refine**
   - feedback on what worked and what did not
   - clarify or adjust your description
   - request iterations until satisfied
4. **Integrate your own expertise and judgment**
   - add your unique perspective, creativity, domain knowledge
   - **you make the final decisions** on what to keep, modify, discard
   - **take responsibility** for the final output (bridge to Diligence)

Repeat for each task until the project is complete.

```
   ┌──────────── Describe (product / process / performance) ────────────┐
   │                                                                     ▼
 Refine  ◄──── Discern (product / process / performance) ◄──── AI response
   │
   └─► Integrate your expertise → final decision → own the result
```


## What comes next
Diligence: while Delegation, Description and Discernment are mainly about **effectiveness and efficiency**, Diligence covers **ethics and safety**: making collaboration responsible, transparent and accountable.
